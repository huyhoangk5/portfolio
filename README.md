## 🛠️ Công nghệ sử dụng trong Website Portfolio

- **Frontend Core:** React 18, TypeScript, HTML5, Vanilla CSS3 (Custom Grid & Flexbox, không phụ thuộc Tailwind).
- **Build Tool:** Vite 4.2 với SWC compiler.
- **Đa ngôn ngữ (i18n):** React Context API (Hỗ trợ chuyển đổi mượt mà Tiếng Việt 🇻🇳 và Tiếng Anh 🇬🇧).
- **Tự động hóa CI/CD:** GitHub Actions workflow tự động build và deploy lên GitHub Pages khi push code lên nhánh `main`.

## 🚀 Hướng dẫn chạy cục bộ

```bash
# 1. Clone repository
git clone https://github.com/huyhoangk5/portfolio.git
cd portfolio

# 2. Cài đặt các gói phụ thuộc
npm install

# 3. Khởi chạy môi trường phát triển
npm run dev

# 4. Build sản phẩm tối ưu
npm run build
```
